IMD Fleet Services – HTML Einzelseiten Paket

Struktur:
- index.html: Übersicht / Startpunkt
- so-funktionierts.html
- verkaufszeitpunkt.html
- warum-imd.html
- kontakt.html
- details.html
- anfrage.html
- style.css: gemeinsames Designsystem
- assets/: alle Bilddateien einzeln

Wichtig:
- Texte sind nicht in Bildern eingebettet, sondern als HTML editierbar.
- Bilder sind separat im Ordner assets abgelegt.
- Die HTML-Dateien verweisen auf die Bilder über relative Links, z. B. assets/bg_imd_wall.jpg.
- Farbwelt: dunkles Betongrau, Glasflächen, weiche Beleuchtung, weiße/hellgraue Typografie, kaum Blau.
