Fahrer-Onboarding — welcher Ansatz?

Fahrer sind selten eingeloggt (1–2x/Monat). Das beeinflusst die richtige Wahl.

A
Einladungslink → Passwort setzen → E-Mail+Passwort Login
Schema 2 Ansatz — klassisch, bewährt
Klassisch
1
IMD legt Fahrer an
Name + E-Mail im Dashboard eingeben, Fuhrpark zuweisen
POST /api/fahrer
2
Einladungs-E-Mail automatisch versendet
Link: /fahrer/aktivieren?token=abc123 — 72h gültig, einmalig
Resend E-Mail
3
Fahrer setzt Passwort
Öffnet Link → gibt Passwort ein → Account aktiv. Token wird gelöscht.
4
Login: E-Mail + Passwort
Bei jedem Zugriff. Formular wird automatisch vorausgefüllt.
POST /api/fahrer/login
✓ Einfach zu implementieren ✓ Fahrer kennen E-Mail+Passwort ✗ Fahrer vergessen Passwort nach Monaten ✗ "Passwort vergessen" Flow nötig
Gut wenn: Fahrer täglich oder wöchentlich einloggen
B
Einladungslink → kein Passwort → Magic Link Login
Passwordless — modern, kein "Passwort vergessen"
★ Empfohlen für Fahrer
1
IMD legt Fahrer an
Name + E-Mail im Dashboard — gleich wie Option A
2
Einladungs-E-Mail → Account sofort aktiv
Kein Passwort nötig. Fahrer klickt Link → direkt eingeloggt, Formular fertig.
Account aktiv nach erstem Klick
3
Jeder spätere Login → neuer Magic Link
Fahrer gibt E-Mail ein → bekommt sofort einen Login-Link → klickt → fertig. 15 Minuten gültig.
POST /api/fahrer/magic-link
✓ Kein Passwort vergessen — nie ✓ Einfachster Flow für selten loggenden Fahrer ✓ Kein "Passwort vergessen"-Feature nötig Modern — verwendet von Notion, Linear, Slack ✗ Braucht E-Mail-Zugang beim Login
★ Perfekt für Fahrer: selten eingeloggt (1–2x/Monat) → Passwort wäre immer vergessen
C
Einladungslink → Passwort + Magic Link als Fallback
Hybrid — flexibel, mehr Implementierungsaufwand
Zukunft
1
Wie Option A — Einladung + Passwort setzen
Standard-Passwort-Flow beim ersten Mal
2
Login: E-Mail+Passwort ODER "Link schicken"
Fahrer kann wählen. "Passwort vergessen" entfällt — einfach Magic Link anfordern.
✓ Maximale Flexibilität ✗ Doppelter Implementierungsaufwand ✗ Für Phase 1 zu komplex
Sinnvoll in Phase 2 wenn Fahrer häufiger einloggen
Klick eine Option an, dann zurück ins Terminal
